================================================================================
FLUXO ESPERADO (SESSAO 9)
================================================================================

STARTUP (t=0-30 s):
  Robo estatico em odom(0,0). Nav2 sobe em t=20s, docking server em t=25s.

t=30 s -> RETURNING_HOME -> DOCKING:
  _autostart() dispara. DockRobot(navigate_to_staging_pose=True) e enviado.
  Servidor navega ate staging odom(12,0) depois aborda dock odom(13,0).

t~90-120 s -> HOME_CHARGING:
  DockRobot reporta sucesso. _dock_res() verifica posicao fisica:
    dist = sqrt((robot_x - 12.7)^2 + robot_y^2) <= 0.5 m E |yaw| <= 10 graus
  Se OK -> HOME_CHARGING. Se longe -> retry.
  Bateria comeca a carregar a 1%/s.

HOME_CHARGING + bat >= 40% + tarefa na fila:
  [UNDOCKING] -> [GOING_TO_TASK] -> [EXECUTING_TASK] -> [RETURNING_HOME]
  -> [DOCKING] -> verifica posicao fisica -> [HOME_CHARGING]

Regras de bateria:
  bat >= 40% + fila -> aceita proxima tarefa
  bat <  20% apos tarefa -> retorna imediatamente
  bat <=  5% durante tarefa -> aborta e retorna (emergencia)
  HOME_CHARGING -> carregando sempre

================================================================================
ATENCAO -- LICOES APRENDIDAS
================================================================================

- NAO usar pkill dentro do launch file (mata o proprio processo)
- wait_for_server() em callbacks bloqueia o executor -> usar server_is_ready() + _once()
- navigate_to_staging_pose=True da resultado mais preciso que navegar manualmente
- docking_threshold muito apertado (0.02) impede DockRobot de declarar sucesso
- Verificar POSICAO FISICA (2D) antes de declarar HOME_CHARGING:
    checar so Y e yaw permite que spawn em (0,0,yaw=0) passe a verificacao
    solucao: dist 2D = sqrt(dx^2+dy^2) <= tolerancia (bloqueia posicoes distantes)
- Nunca forcar HOME_CHARGING em fallback de falha de docking:
    o robo pode estar longe do dock quando DockRobot falha repetidamente
    solucao: pausa + retentar (nao assume estado sem confirmacao fisica)
- AUTOSTART_DELAY deve ser > tempo de inicializacao do docking server (25 s):
    usar 30 s garante que Nav2 e docking server estejam prontos
